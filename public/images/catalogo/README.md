# Artes editoriais do catálogo

As 19 fragrâncias usam uma única arte oficial com os frascos de 50 ml e
500 ml apresentados juntos. Os PNGs foram copiados sem recompressão e usam o
slug canônico de cada fragrância:

- `baby.png`
- `black-cherry.png`
- `black-vanity.png`
- `brown.png`
- `choc.png`
- `citric.png`
- `explosion.png`
- `flowers.png`
- `glamour.png`
- `gold.png`
- `illusion.png`
- `jasmin.png`
- `mango.png`
- `night.png`
- `strawberry.png`
- `style-g.png`
- `sweet.png`
- `watermelon.png`
- `you.png`

As imagens são exibidas integralmente com `object-fit: contain`, sem recorte,
filtro ou recompressão.
