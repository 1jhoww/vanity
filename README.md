# Vanity Pet

Site institucional de uma marca dedicada a perfumes para cães e gatos. O
projeto usa React, Vite, JavaScript, CSS Modules e React Router.

O catálogo renderiza dinamicamente produtos e apresentações, ignora itens
indisponíveis e está preparado para destaques, lançamentos, coleções e novos
volumes. Nomes, descrições e informações olfativas específicas permanecem
pendentes de validação oficial.

Requer Node.js 22.22 ou superior.

## Comandos

- `npm run dev` — ambiente local
- `npm run lint` — análise estática
- `npm run build` — build de produção

O arquivo `vercel.json` mantém as rotas da SPA funcionando em um deploy futuro.
